I encountered runtime error when calling model = torch.nn.SyncBatchNorm.convert_sync_batchnorm(model) while using mixed precision training with multiple GPUs.

The issue turns out to be with this function, torch.batch_norm_gather_stats_with_counts, which requires count_all, running_mean, running_var to have same dtype. In fp16 mode, running_mean, running_var are fp16, but, count_all is fp32 because it has same dtype as mean, which is computed line 25 (whose return dtype is fp32 although input's dtype is fp16).
So one solution could be instead of assigning count.dtype=mean.dtype, line27, let count.dtype=running_mean.dtype, or convert count_all.view(-1).to(running_mean.dtype) when calling batch_norm_gather_stats_with_counts
