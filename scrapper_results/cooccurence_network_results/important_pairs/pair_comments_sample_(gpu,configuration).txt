Issue description
When normalizing within torch.stft, the function divides by the $\sqrt{framelength}$ or otherwise $\sqrt{nfft}$. This would make sense for a rectangular window, or when the window is None.
When window is not None, or it is not a rectangular window however, it would make sense to normalize with regards to the values within the window, as can be seen in the link below, you normalize with the L2 norm of the window
https://ccrma.stanford.edu/~jos/sasp/Normalized_STFT_Basis.html
This is especially applicable when using normalizing for audio spectrograms, where the default window is a hann_window.
I believe that normalization should happen with output /= window.pow(2.0).sum().sqrt() If window is None like default, then it should fall back to its current normalization.
